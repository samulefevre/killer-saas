## Done when
- Codex commands/agent skills select explicit model and reasoning effort at delegation;
  neither Claude opus equivalence nor inherited session model determines Codex routing.
- Default routing: orchestrator Sol low; status/bootstrap/ship Luna high; PRD/stories,
  research synthesis/plan/flow and ordinary implementation Sol medium; architecture,
  stories review and code review Sol high; visual design Terra medium; tightly scoped
  chores and targeted code discovery Luna high. All IDs use GPT-6.1 Sol/Terra,
  GPT-6 Luna, GPT-6 Astra exactly as approved in this chat.

  conflicting evidence or expanded scope escalate to Sol medium. In every project, economy,
  authentication/sessions, database transactions and cross-language determinism require
  Sol high for substantive analysis, planning, implementation and review.
- Persistent hard problems escalate to Astra medium, then high if necessary; escalation
  states the reason and hands off evidence. No max/ultra or extra review by default.
- Routing does not create extra pipeline phases or bypass existing gates. A main session
  that cannot switch models states that limit; never claim a prompt changed its model.
- Explicit spawn model/effort uses a fresh context when required by the host; if model
  selection is unavailable, report it rather than silently claiming the desired model.
- Dreadkin is covered by these generic risk categories (including SQLite/D1 and Godot/TS)
  without any project setting or manually maintained per-project model policy.
- Generic routing ships with the method for every project, without a Dreadkin-only switch
  or required per-project copy of the default model table. Existing installs receive it on
  reinstall/update; do not silently modify unrelated project working directories.
- Keep the existing installer unchanged if it already transports the generated routing.
  openai.yaml interface metadata must not be presented as a runtime model selector.
- If verification demonstrates an installer change is necessary, make it only in this
  source fork, never in an installed cache; document the reason and focused verification.
- Installer output preserves Claude behavior, project settings, unrelated Codex settings
  and unrelated installed skills. Dreadkin Codex installation matches generated output.
